# 2048 Undo

2048 with unlimited undo. Installable web app (PWA) for iPhone: open the page in Safari → Share → "Add to Home Screen".

- Unlimited undo (also from the game-over screen), fresh random spawn after every undo
- Board sizes 3×3 to 8×8, each with its own game, best score and local leaderboard
- Game state is saved after every move and restored on launch
- Works offline
